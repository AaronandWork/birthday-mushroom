# 蘑菇崽的生日派对 🍄

一个手写的生日祝福网站：星空开场、吹蜡烛、拆信封、拍立得相册、接孢子小游戏、孔明灯和生日卡片导出。

**在线看**：https://aaronandwork.github.io/birthday-mushroom/

纯 HTML / CSS / 原生 JavaScript，没有框架、没有构建步骤、没有外部依赖。音乐、音效、烟花、彩纸全部由浏览器实时生成。

---

## 六个章节

| 章节 | 内容 |
| --- | --- |
| 01 开场 | 星空光斑、鼠标视差、点小蘑菇会跳、数字滚动、跑马灯 |
| 02 吹蜡烛 | 三层蛋糕，点蜡烛 / 按空格 / 开麦克风吹灭，彩纸 + 烟花 |
| 03 一封信 | 火漆信封 → 信纸展开 → 手写体逐字打字 |
| 04 相册 | 五张拍立得，3D 倾斜、灯箱放大 |
| 05 小游戏 | 20 秒接孢子，连击倍率、最高分本地保存 |
| 06 许愿 | 写愿望放孔明灯、放烟花、导出 1080×1440 生日卡片 |

## 改成送给别人

改 `assets/js/app.js` 顶部的 `CONFIG`（名字 / 日期 / 信的内容），替换 `assets/img/g1~g5.jpg` 和 `mascot.png` 即可。

## 技术点

- 抠图：HSV 颜色距离 + 边界洪泛 + 绿色溢出去污 + 羽化，生成白边贴纸
- 音乐：Web Audio 实时合成 8 小节原创摇篮曲，卷积混响的脉冲响应是运行时生成的
- 粒子：单张固定 Canvas 管理彩纸 / 烟花 / 孢子 / 光标火花，无粒子时自动停 rAF
- 可访问性：键盘路径、aria 标签、`prefers-reduced-motion` 降级
